J'ai entièrement réécrit le composant `Header.tsx` en repartant de zéro pour corriger définitivement les problèmes que vous rencontriez. J'ai été très méticuleux pour m'assurer que tout fonctionne comme il se doit.

Le nouveau `Header` a un comportement standard et robuste :
- Une barre de navigation unique, **fixe en haut de l'écran** sur tous les appareils.
- Sur mobile, un **bouton "hamburger"** ouvre un **menu en plein écran**.
- Ce menu contient **tous les liens de navigation** ainsi que les **boutons pour changer de langue/thème et pour s'inscrire**.
- Le **bouton pour fermer le menu (X)** est clairement visible.
- J'ai également fait en sorte que le défilement de la page soit bloqué lorsque le menu mobile est ouvert, pour une meilleure expérience utilisateur.

Toutes les logiques complexes et sources de bugs des versions précédentes ont été supprimées.

Je suis confiant que cette nouvelle version est la bonne. Veuillez, s'il vous plaît, vérifier une dernière fois.
